# Ручной дымовой прогон

Без зависимостей. Три языка × этот список. Телефон и ноутбук.

## RU · EN · DA

1. Экран языков. Три имени. Внизу «Метод · Method · Metode».
2. Метод открывается без фразы. Есть сталь/трещина/документ и журнал.
3. Назад на языки, выбрать язык.
4. Видны 7 фраз, «другие фразы», «своя». Не сгруппированы по сторонам.
5. «другие фразы» раскрывает остальные. Порядок тот же при обновлении вкладки.
6. Выбрать фразу → вопрос о норме этой почвы (не общий). Нет «к тексту».
7. Ответ → полоса: кикеры Сталь / Документ на первом экране, Трещина в эссе.
8. Документ: дата, URL, archive, why. Если есть quote — видна.
9. «Другие аргументы» — остальные папки этой фразы.
10. После двух аргументов появляется «Протокол чтения».
11. Протокол — `<pre>`: фраза, названная норма, норма в статье, различения, документы. Без кнопок.
12. Своя разобранная фраза («голод как оружие») → guess → famine/blockade.
13. Своя «абракадабра» → почва неизвестна → 16 различений → guess → аргумент со строкой «Почва неизвестна…».
14. Чистая сессия, открыть `#/<lang>/famine` → «Эту страницу читают после фразы» → фраза → guess → famine.
15. Печать полосы: один лист, URL в скобках, без «других аргументов».
16. DevTools → Network: нет запросов к чужим доменам (только свои файлы).

Не должно быть: skip, CTA, шаринга, счётчиков, аналитики, очков.
